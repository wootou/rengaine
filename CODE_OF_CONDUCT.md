# Code of conduct

Rengaine follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, welcome newcomers, criticise ideas and code rather than people, and
assume good faith. Harassment, insults and discrimination are not tolerated, in issues, pull requests or
any other project space.

Report unacceptable behaviour privately to the maintainers (see SECURITY.md for the private reporting
channel). Maintainers may remove comments, close discussions or ban participants who break these rules.
