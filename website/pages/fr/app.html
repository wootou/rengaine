L'appli Android

Rengaine pour Android emporte votre bibliothèque dans la poche. L'appli se connecte à votre propre serveur Rengaine et joue votre musique en arrière-plan, écran verrouillé ou au casque Bluetooth. Elle ne fournit aucune musique et n'envoie rien ailleurs qu'à votre serveur.

Télécharger l'APK sur GitHub

Reprenez là où vous en étiez

Votre file d'attente, vos favoris, vos playlists et vos réglages sont ceux du site : une écoute commencée sur l'ordinateur continue sur le téléphone. Pour relier l'appli, scannez le QR code affiché par le site (Réglages › Appareils connectés › Appairer un appareil), ou entrez l'adresse du serveur, votre e-mail et votre mot de passe. Plusieurs comptes peuvent cohabiter.

Ce qu'elle sait faire

  • Albums, Artistes, Explorer (ambiances, genres, décennies), Aléatoire, Playlists, Mes favoris ;
  • recherche pendant la frappe, historique d'écoute ;
  • file d'attente synchronisée avec le site, mode infini, lecture continue ;
  • forme d'onde dans le lecteur ;
  • playlists : créer, renommer, partager, ajouter et retirer des pistes ;
  • appareils connectés (et appairage d'un autre appareil), export des données, suppression du compte ;
  • thème clair ou sombre, en français et en anglais.

Pensée pour le téléphone

  • lecture en arrière-plan, avec les commandes dans la notification et sur l'écran verrouillé ;
  • boutons du casque et du Bluetooth ;
  • cache des morceaux déjà écoutés (de 250 Mo à 5 Go), qui repartent sans attendre ;
  • qualité du flux selon le réseau : une version Opus allégée sur les données mobiles ;
  • écoutes gardées sur le téléphone hors connexion, puis envoyées au retour du réseau.

Prévu : changer son nom et son mot de passe dans l'appli (pour l'instant sur le site), réordonner les pistes d'une playlist, fondu enchaîné, images de fond, tablettes, télécommande partagée, musique téléchargée pour l’écoute hors connexion, Android Auto, widget, Chromecast.

Télécharger

Version de test 1.0.0-rc.1, pour Android 12 ou plus récent. L'APK (rengaine-1.0.0-rc.1.apk) est dans la version publiée sur GitHub. Une publication sur le Play Store est prévue.

  • Pas de mise à jour automatique en dehors du Play Store : surveillez les versions publiées, ou utilisez Obtainium.
  • Adresse du serveur en https:// conseillée ; http:// est accepté, avec un avertissement.
  • Pour vérifier qu'un APK vient bien de Rengaine, apksigner verify --print-certs doit afficher cette empreinte SHA-256 du certificat : C4:DD:73:38:7F:C0:CD:E5:3F:1B:17:BE:5E:41:C5:3D:58:A2:6C:A5:55:50:5D:39:91:7C:99:91:93:4A:CF:E2
